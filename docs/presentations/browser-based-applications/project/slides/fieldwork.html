An example

Fieldwork is a browser-based application

Opened from a link

fieldwork-app.github.io/fieldwork: nothing to install, the latest version on every visit.

Computed in your tab

Rates, maps, regressions and its reasoning engine all run on your computer.

Saved on your device

Projects and data are kept in your browser, and open offline once loaded.

Shared when you choose

Back up to a file, or save a project to a GitHub repository with colleagues.

Now Fieldwork itself. It is served from GitHub Pages, which only hands out the program. Every computation, from a rate to a regression to the reasoning engine that checks rules, runs in your own browser tab. Projects are kept in the browser's own storage, and the application opens offline after the first visit. When you want to share, you back up to a file or save to a GitHub repository, as a collaborative project does.
